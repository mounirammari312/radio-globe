## ✨ الميزات

### مطابقة لـ Radio Garden:
- 🌐 **MapLibre GL JS** + globe projection (نفس المكتبة)
- 🎵 **HLS.js** لبث m3u8 (مثل RTL, BBC, NPR)
- 🟢 نقاط خضراء `rgb(0, 224, 112)` مطابقة للأصل
- 🔵 خلفية deep blue `rgb(8, 4, 30)` مطابقة
- ✛ Crosshair في المركز للإحساس بـ "tuning"
- 🔄 دوران تلقائي يتوقف عند التفاعل
- 📍 منظومة **Places** (محطات مجمّعة حسب الموقع)
- 📋 شريط جانبي 380px على الديسكتوب

### تحسينات Vercel:
- 🚀 **Build-time data fetch** (سكريبت prebuild) - لاcold start timeout
- ⚡ **API <50ms** (يقرأ من JSON ثابت، لا اتصال بـ Radio Browser أثناء التشغيل)
- 🔀 **Stream proxy** `/api/proxy?url=...` لتجاوز قيود CORS
- 📱 **MediaSession API** - تحكم من شاشة قفل الهاتف + الإشعارات
- 📄 **صفحات قانونية** كاملة (privacy, terms, about, contact)
- 💰 **Ad Container** مع تحديث ذكي كل 45 ثانية (متوافق مع AdSense)
- 🆘 `ads.txt` و `robots.txt` جاهزان

## 🚀 النشر على Vercel

### 1️⃣ ارفع إلى GitHub

```bash
# بعد فك ضغط ملف ZIP
git init
git add .
git commit -m "Radio Globe - Vercel-ready Radio Garden clone"
git branch -M main
git remote add origin https://github.com/USERNAME/radio-globe.git
git push -u origin main
```

### 2️⃣ اربط المستودع على Vercel

1. اذهب إلى [vercel.com/new](https://vercel.com/new)
2. اختر مستودع `radio-globe`
3. Vercel سيكتشف Next.js تلقائياً
4. الـ `buildCommand` مُعدّ مسبقاً في `vercel.json` ليُشغّل `bun run prebuild && next build`
5. اضغط **Deploy**

### 3️⃣ (اختياري) تفعيل Google AdSense

لتفعيل الإعلانات على الموقع:

1. أنشئ حساب [Google AdSense](https://www.google.com/adsense/)
2. احصل على معرّف الناشر: `ca-pub-XXXXXXXXXXXXXXXX`
3. أضف متغير البيئة على Vercel:
   - **Key:** `NEXT_PUBLIC_ADSENSE_CLIENT`
   - **Value:** `ca-pub-XXXXXXXXXXXXXXXX`
4. حدّث `public/ads.txt` بمعرّفك بدل `pub-0000000000000000`
5. حدّث slot IDs في `src/components/ads/ad-container.tsx`
6. أعد النشر — سيظهر الإعلان أسفل المشغّل

### 4️⃣ (اختياري) تحديث بيانات المحطات

لتحديث قائمة المحطات (أسبوعياً مثلاً):

```bash
# محلياً:
bun run build:data

# أو عبر Vercel Cron Job:
# 1. اذهب لإعدادات المشروع على Vercel
# 2. أضف Cron Job يُشغّل البناء كل أسبوع
```

## 🎯 استراتيجية الأداء

### 1. Pre-build Data Fetching (no cold start timeout)

بدلاً من جلب 40,000 محطة أثناء طلب الزائر الأول (يُسبب 504 timeout على Vercel):
- سكريبت `scripts/build-places.ts` يعمل أثناء البناء فقط
- يُحفظ الناتج في `public/data/*.json`
- الـ API يقرأ من هذه الملفات → استجابة <50ms
- يُعاد البناء تلقائياً على كل deploy

### 2. Stream Proxy (CORS bypass)

عندما يفشل البث بسبب CORS، المشغّل يُحاول عبر `/api/proxy?url=...`:
- يُضيف ترويسة `Access-Control-Allow-Origin: *`
- يُمرّر `Range` requests لـ HLS و seeking
- مهلة 25 ثانية (متوافق مع Vercel Hobby)

### 3. MediaSession API

عند تشغيل محطة، يظهر على شاشة قفل الهاتف:
- اسم الإذاعة + الدولة + الصورة
- أزرار: تشغيل/إيقاف، المحطة التالية، السابقة
- يتكامل مع سماعات البلوتوث و Android Auto

### 4. Smart Ad Refresh

- الإعلان يُحدّث كل **45 ثانية** فقط أثناء التشغيل
- يتوقف عن التحديث عند الإيقاف (يحفظ ميزانية الإعلان)
- متوافق مع سياسات Google AdSense (≥30s)

### 5. Static Data Caching

ملفات `public/data/*.json`:
- تُخزَّن على Vercel CDN
- ترويسة `Cache-Control: max-age=604800, immutable`
- تحميل سريع عالمياً
